# دليل الدير — تطبيق أندرويد

تطبيق أندرويد بلغة **Flutter** مطابق لموقع دليل الخدمات اليومية، بتصميم عصري و**قاعدة بيانات SQLite محلية** تعمل **بدون إنترنت**.

## ✨ المميزات

### التصفح
- **تنقّل على مستويين**: بطاقات التجميع (منطقة / اختصاص / نوع مركبة) ← خدمات تلك المجموعة فقط
- **بطاقات مربّعة** (٣ في الصف): أيقونة + اسم + نقطة حالة مع نص صغير
- **لوحة تفاصيل سفلية** تُحدَّث في مكانها عند اختيار خدمة أخرى (لا تتراكم)
- **مفتاح بطاقات/قائمة** فاعل في **كل** الأقسام
- فلاتر: المحافظات ← النطاق ← الحالة (الكل / تعمل الآن / مقلقة / مناوبة) ← بحث
- **carousel إعلانات** يُغذّى من لوحة التحكم، والفاصل الزمني قابل للضبط

### الخدمة
- صفحة تفاصيل كاملة: حالة، عنوان، هاتف، منطقة، ملاحظات، جدول دوام أسبوعي
- **زر اتصال** مباشر و**زر واتساب**
- «أضف خدمتك» على صفحة التفاصيل (وليس في شريط التنقل)
- حفظ في **المفضلة** (محلياً)

### الحساب والمالك
- تسجيل الدخول / إنشاء حساب بـ **تبويبات مُنمّقة**
- الاسم الكامل + رقم الهاتف + تاريخ الميلاد
- **لوحة المالك**: تبديل الحالة بالسحب (Switch)، تفعيل **المناوبة**، تعديل **جدول الدوام**
- متابعة **طلباتي** وحالة كل طلب

### بدون إنترنت
- **كل البيانات تُحفظ في SQLite محلياً** — التصفح والبحث يعملان بلا شبكة
- **مزامنة تلقائية** عند عودة الاتصال
- شريط تنبيه أصفر يوضّح أن البيانات معروضة من الذاكرة المحلية

## 🗄️ قاعدة البيانات المحلية (SQLite)

الجداول في `lib/services/database_service.dart`:

| الجدول | المحتوى |
|---|---|
| `categories` | الأقسام |
| `governorates` | المحافظات |
| `regions` | المناطق (مدن وقرى) |
| `specialties` | الاختصاصات الطبية |
| `services` | الخدمات (كل حقول الخادم) |
| `schedules` | جداول الدوام (٧ أيام لكل خدمة) |
| `settings` | إعدادات التطبيق |
| `sync_meta` | وقت آخر مزامنة |
| `favorites` | المفضلة |
| `recent_searches` | آخر عمليات البحث |

**استراتيجية العمل**: المحلي أولاً (إقلاع فوري بلا شاشة تحميل) ← مزامنة في الخلفية ← الرجوع للمحلي عند فشل الشبكة.

## 🏗️ بنية المشروع

```
lib/
├── main.dart                    نقطة الدخول + الثيم + مزوّدات الحالة
├── config/
│   ├── constants.dart           رابط الخادم، إعدادات الأقسام، الألوان
│   ├── theme.dart               نظام التصميم (أبيض + أزرق فاتح)
│   └── icons.dart               خريطة أيقونات Lucide + أيقونة الإسعاف المرسومة
├── models/models.dart           كل النماذج مطابقة لاستجابات الـ API
├── services/
│   ├── api_service.dart         عميل HTTP (login · meta · services · owner)
│   └── database_service.dart    SQLite محلي (حفظ · قراءة · مفضلة · بحث)
├── providers/
│   ├── app_provider.dart        البيانات المرجعية + المزامنة + الاتصال
│   └── auth_provider.dart       الجلسة والمصادقة
├── screens/                     الشاشات (١١ شاشة)
└── widgets/widgets.dart         ودجات مشتركة (بطاقات · شرائح · حالات)
```

**٨٨٩٢ سطر** من شفرة Dart · **٢٠ ملفاً** · **صفر أخطاء تحليل**

## 📱 نقاط الـ API المستخدمة

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/health` | فحص الخادم |
| GET | `/meta` | الأقسام · المناطق · المحافظات · العدّادات · الإعدادات |
| GET | `/services` | الخدمات (فلترة: قسم · محافظة · منطقة · حالة · بحث) |
| GET | `/services/{id}` | تفاصيل خدمة مع جدول الدوام |
| GET | `/specialties` | الاختصاصات الطبية |
| POST | `/auth/login` | تسجيل الدخول |
| POST | `/auth/register` | إنشاء حساب |
| GET | `/auth/me` | بيانات المستخدم |
| GET | `/my/services` | خدمات المالك |
| GET | `/my/requests` | طلبات المالك |
| PUT | `/owner/services/{id}/status` | تبديل الحالة / المناوبة |
| PUT | `/owner/services/{id}/schedule` | حفظ جدول الدوام |

## 🚀 طريقة البناء

### المتطلبات
- Flutter **3.24** أو أحدث
- Android SDK (compileSdk 34)
- JDK 17

### الأوامر

```bash
# ١) ثبّت الحزم
flutter pub get

# ٢) تحقّق من البيئة
flutter doctor

# ٣) شغّل على جهاز متصل
flutter run

# ٤) ابنِ APK للتوزيع
flutter build apk --release

# ٥) أو حزمة التطبيق الكاملة (موصى به للمتجر)
flutter build appbundle --release

```


## 🎨 التصميم

- **خلفية بيضاء + لمسات أزرق فاتح** (`#0EA5E9`) — مطابق لموقع الويب، **ليس** وضعاً ليلياً
- خط **Cairo** العربي
- **دعم كامل للاتجاه من اليمين لليسار (RTL)**
- حقول إدخال مُنمّقة: حدود واضحة، حشو مريح، حالة تركيز بلون أساسي
- تبويبات مُنمّقة في الدخول ولوحة المالك
- ظلال ناعمة وزوايا دائرية (١٠–٢٦ بكسل)
- **أيقونة الإسعاف** مرسومة يدوياً (غير متوفرة في حزمة Lucide)

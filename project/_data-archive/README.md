وامسح أي قاعدة سابقة»**. حُذفت كل النسخ السابقة فلم تبقَ إلا القاعدة أعلاه:

| الملف المحذوف | ما كان |

| `appnew.sqlite` | نسخة المدير بعد الترحيل — **بلا** إعدادات `app_*`، فبطاقة التحديث لا تعمل عليها |
| `app.sqlite-dalel.txt` · `app.sqlite-daleltest.txt` | لقطتان نصيّتان لقاعدتَي dalel/daleltest اللتين استُخدمتا في المقارنة والترحيل |

| `_data-archive/deprecated/*.sqlite` (٣ ملفات) | نسخ منشورة قديمة: حلب (٥٢٣ خدمة) ولقطتا ما قبل ترحيل الحقول |

> 📌 **لا شيء فُقد نهائياً:** كل هذه الملفات محفوظة في **تاريخ Git** (المستودع)،
> ويمكن استرجاع أيٍّ منها بـ`git show <commit>:<path>`. حُذفت من الشجرة
> الحالية فقط كي لا يبقى في المستودع أكثر من قاعدة واحدة يُحتمل الالتباس بينها.

**تحذير:** لا تُعِد أي نسخة منها إلى الخادم — قاعدة الخادم الحيّة هي الأحدث دائماً،
